# Support

## Questions and usage help

For setup questions, API usage, migration guidance, and design discussion, use
GitHub Discussions if enabled. If Discussions are unavailable, open a regular
GitHub issue with the `question` label after searching existing issues.

Please include the `tdesign-gpui`, GPUI, Rust, and operating-system versions plus
a minimal code sample. The project is community-maintained and cannot guarantee
response times or private integration support.

## Bugs and feature requests

Use the structured issue forms:

- bug report for reproducible incorrect behavior;
- feature request for new APIs, components, or native adaptations.

TDesign parity reports should link the exact React PC documentation/API field and
explain how it should map to GPUI. GPUI crashes or rendering defects that reproduce
without this library may need an upstream Zed/GPUI report as well.

## Security and conduct

- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never report them publicly.
- Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for community interactions.
- This project is unofficial and cannot provide Tencent, TDesign, or Zed product support.
